### Requirements

Make sure you have installed:

- Java 17+

- Maven 3+

- MariaDB or MySQL Server

- Bash shell (for running .sh scripts)

Ensure mariadb is up and running

### How to start program:

Clone repository

Go to erp folder\
`cd erp/`

Run following shell scripts\
`./refresh.sh`\
`./setup.sh`\
`./run.sh`

Every subsequent time you wish to run program, do\
`./run.sh`

### How to run tests
`mvn clean test`

Other materials like reports, demos etc. are in materials
